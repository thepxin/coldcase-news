# \# Anthropic launches Claude Ship to review, fix and approve code changes on GitHub

# type: report

# 

# Anthropic announced Claude Ship, a set of artificial intelligence agents that review, fix and approve code changes, on Monday, November 23, 2026 (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

# 

# According to TechCrunch, Claude Ship is launching in beta and rolling out to Claude Team and Enterprise plans for repositories on GitHub (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)). Code Review is generally available, while PR Steward and Claude Approvals are in beta (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

# 

# PR Steward addresses issues such as failing continuous integration checks, merge conflicts and feedback from Code Review (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)). After every push, it comments on what it changed and how to roll the change back, if needed (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

# 

# Claude Approvals then applies an approval policy that each team writes in natural language, as a file in the repository (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)). The approval process can draw on signals that include Code Review findings or a company's own classifiers (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

# 

# Because the offering is still in beta, Anthropic suggests running the approval function in observe-only mode first (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)). Teams can also start with just one repository and set monthly spending limits for more control over the process (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

# \## Details (as Reported)

# 

# \- In a blog post, the company wrote that "Most teams want a person to approve every change," noting that this is easy to keep up with when people write every line (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

# \- The same post stated: "On the Claude Code team, Claude writes most of our code" (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

# \- The post added that the team wanted everything after the pull request to move as quickly as the writing of the code (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

# \- Teams keep control over which review setting to use, such as Quick, Standard or Deep, and over which changes are escalated to a human for a decision (\[TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).
