# Microsoft adds containment for artificial intelligence agents and expands a Defender preview
type: report

Microsoft announced on November 5, 2026, that Microsoft Execution Containers, an operating system-enforced containment layer for artificial intelligence agents, is now generally available ([Microsoft Security](https://www.microsoft.com/en-us/security/blog/2026/11/05/whats-new-in-microsoft-security-november-2026/)).

In guidance dated November 10, 2026, Microsoft Partner Center described how the company is extending Project Perception with Guardian Agents, which supervise the actions of every agent and respond in real time as risk rises ([Microsoft Partner Center](https://learn.microsoft.com/en-us/partner-center/announcements/2026-november)). At Microsoft Ignite 2026, the company expanded the public preview of Integrated Security Operations Center in Microsoft Defender, which brings security information and event management and threat protection together in Defender ([Microsoft Partner Center](https://learn.microsoft.com/en-us/partner-center/announcements/2026-november)).

In the same November 5 update, Microsoft added new system settings support to Microsoft Intune Endpoint Privilege Management and introduced new Microsoft Defender Experts managed detection and response experiences in the Microsoft Defender portal ([Microsoft Security](https://www.microsoft.com/en-us/security/blog/2026/11/05/whats-new-in-microsoft-security-november-2026/)). The enhanced agent for Defender for SQL Servers on machines is now generally available, which removes the need to deploy the Azure Monitor Agent for that scenario ([Microsoft Security](https://www.microsoft.com/en-us/security/blog/2026/11/05/whats-new-in-microsoft-security-november-2026/)).

## Details (as Reported)

- Microsoft Partner Center described agents as often having overprivileged access to data, tools and systems, and as adapting as context changes ([Microsoft Partner Center](https://learn.microsoft.com/en-us/partner-center/announcements/2026-november)).
- According to Microsoft Partner Center, Guardian Agents know which agents exist and who owns them, contain what each agent can access before it acts, protect the data, tools and runtime in the agent's path, and adapt protection as context and risk change ([Microsoft Partner Center](https://learn.microsoft.com/en-us/partner-center/announcements/2026-november)).
- Microsoft reported that organisations can tune and validate policies before enforcing them broadly, and that an upcoming integration with Microsoft Intune, Microsoft Entra and Microsoft Agent 365 is intended to extend governance and attribution across the enterprise ([Microsoft Security](https://www.microsoft.com/en-us/security/blog/2026/11/05/whats-new-in-microsoft-security-november-2026/)).
- Microsoft Partner Center reported that Integrated Security Operations Center now offers the full breadth of security information and event management capabilities and an opt-in path for existing Microsoft Sentinel customers ([Microsoft Partner Center](https://learn.microsoft.com/en-us/partner-center/announcements/2026-november)).
- The expanded preview builds on an announcement on September 23, according to Microsoft Partner Center ([Microsoft Partner Center](https://learn.microsoft.com/en-us/partner-center/announcements/2026-november)).
