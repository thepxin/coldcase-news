OpenAI published a customer story on 2026-11-02 about Qodo, a company that builds AI tools for code review and software quality, and its plugin in the Codex marketplace ([OpenAI](https://openai.com/index/qodo-codex-plugin)). The plugin gives Codex access to codebase knowledge, organizational rules and independent review through Qodo's Agentic Toolbox ([OpenAI](https://openai.com/index/qodo-codex-plugin)).

Qodo uses OpenAI models including GPT‑6 Astra to gather engineering knowledge, review code and monitor software quality ([OpenAI](https://openai.com/index/qodo-codex-plugin)). Its Codex plugin brings that context and review into developers' coding sessions ([OpenAI](https://openai.com/index/qodo-codex-plugin)).

## Details (as Reported)

Qodo co-founder and CEO Itamar Friedman calls the company's tooling "the coding agent’s best friend" ([OpenAI](https://openai.com/index/qodo-codex-plugin)). He describes customer environments that can span 10,000 or more repositories, where a local code change can break a downstream service even if it looks correct on its own ([OpenAI](https://openai.com/index/qodo-codex-plugin)). The plugin was built to address that problem ([OpenAI](https://openai.com/index/qodo-codex-plugin)).

With context from the plugin, Codex can account for dependencies across repositories, including those hosted by different Git providers or services connected through Kafka ([OpenAI](https://openai.com/index/qodo-codex-plugin)). Before Codex writes code, it can use the plugin to retrieve the relevant codebase rules and pull request history and patterns ([OpenAI](https://openai.com/index/qodo-codex-plugin)). After the changes are made, Qodo reviews them and returns its findings directly to Codex in the same session, before the developer opens a pull request ([OpenAI](https://openai.com/index/qodo-codex-plugin)).

Nnenna Ndukwe, Qodo's AI Developer Relations Lead, sees developers using the workflow to build features and tackle technical debt with GPT‑6 models in Codex ([OpenAI](https://openai.com/index/qodo-codex-plugin)). Internally at Qodo, she has used GPT‑6 Astra's Extra High and Ultra effort settings in her own automated development workflows and in knowledge work ([OpenAI](https://openai.com/index/qodo-codex-plugin)). She schedules Codex to report on her weekly work, to research conversations about agentic engineering on social platforms, and to suggest agent skills to create or refine ([OpenAI](https://openai.com/index/qodo-codex-plugin)).

Friedman describes coding and review agents as "yin and yang": one creates code and the other challenges it ([OpenAI](https://openai.com/index/qodo-codex-plugin)). He sees an opportunity to use OpenAI's recently launched Decisions API to choose which rules and agent skills apply at each stage of development ([OpenAI](https://openai.com/index/qodo-codex-plugin)). As an example, he cites the API selecting which of 200 rules need checking before a language model reasons through the relevant ones ([OpenAI](https://openai.com/index/qodo-codex-plugin)).
