Microsoft is beginning the rollout of Windows 11 preview update KB5127936, adding a customizable right-click menu ([Ars Technica](https://arstechnica.com/gadgets/2026/10/windows-11-gets-right-click-menu-improvements-as-pc-revenue-slides/)). The cumulative update covers Windows 11 versions 26H2 and 25H2 ([Microsoft](https://support.microsoft.com/en-au/servicing/os/windows-11/2026/10/kb5127936-windows-11-25h2-26h2-update)). The company describes the new menu as faster, simpler and more customizable ([Microsoft](https://support.microsoft.com/en-au/servicing/os/windows-11/2026/10/kb5127936-windows-11-25h2-26h2-update)).

## Details (as Reported)

Microsoft states that users can turn built-in Windows commands, such as Send to and Create shortcut, on or off ([Microsoft](https://support.microsoft.com/en-au/servicing/os/windows-11/2026/10/kb5127936-windows-11-25h2-26h2-update)). Users can add commands such as Print, and choose which app extensions appear in the main menu or a submenu, or hide the submenu ([Microsoft](https://support.microsoft.com/en-au/servicing/os/windows-11/2026/10/kb5127936-windows-11-25h2-26h2-update)). Cut, Copy, Paste, Rename, Delete and Share can be displayed directly in the menu instead of as a row of icons, and Properties can move to the bottom ([Microsoft](https://support.microsoft.com/en-au/servicing/os/windows-11/2026/10/kb5127936-windows-11-25h2-26h2-update)). Holding Shift while right-clicking the desktop shows more options ([Microsoft](https://support.microsoft.com/en-au/servicing/os/windows-11/2026/10/kb5127936-windows-11-25h2-26h2-update)).

In 2021, Microsoft listed problems it aimed to fix in the Windows 10 menu, including that it was exceptionally long and that commands added by apps had no common organizational schema ([Windows](https://blogs.windows.com/blog/2021/07/19/extending-the-context-menu-and-share-dialog-in-windows-11/)). It stated that the Windows 11 menu places common commands next to where the menu is invoked ([Windows](https://blogs.windows.com/blog/2021/07/19/extending-the-context-menu-and-share-dialog-in-windows-11/)).

Ars Technica describes the update as addressing a persistent power user complaint about a right-click menu that disrupted muscle memory and hid some commands behind an additional click ([Ars Technica](https://arstechnica.com/gadgets/2026/10/windows-11-gets-right-click-menu-improvements-as-pc-revenue-slides/)). The newsroom also reported that the announcement came alongside a Microsoft quarterly financial report showing a continued decline in the business of selling Windows licenses for new PCs ([Ars Technica](https://arstechnica.com/gadgets/2026/10/windows-11-gets-right-click-menu-improvements-as-pc-revenue-slides/)).

The preview also features Cloud Rebuild, a recovery option that can reinstall Windows 11 from the cloud even when the existing installation fails to boot ([Ars Technica](https://arstechnica.com/gadgets/2026/10/windows-11-gets-right-click-menu-improvements-as-pc-revenue-slides/)). Ars Technica reported that it pulls the Windows 11 image and system drivers from Windows Update and behaves like a fresh install, so existing applications and files are not included ([Ars Technica](https://arstechnica.com/gadgets/2026/10/windows-11-gets-right-click-menu-improvements-as-pc-revenue-slides/)).

Other changes include a modernized AutoPlay dialog with dark mode support, and support for the tilde character in the File Explorer address bar ([Microsoft](https://support.microsoft.com/en-au/servicing/os/windows-11/2026/10/kb5127936-windows-11-25h2-26h2-update)).
