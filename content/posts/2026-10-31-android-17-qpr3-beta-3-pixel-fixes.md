Google began rolling out Android 17 QPR3 Beta 3 to Pixel devices on October 29, 2026, with a list of 26 fixes ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-pixel/)). The Android developer page for OTA images gives the same release date, October 29, 2026 ([Android](https://developer.android.com/about/versions/17/qpr3/download-ota)). Google states that QPR3 does not include API changes ([Android](https://developer.android.com/about/versions/17/qpr3/download-ota)).

## Details (as Reported)

Google delivers platform updates on a quarterly cadence through Quarterly Platform Releases, which reach AOSP and Pixel devices as part of Feature Drops ([Android](https://developer.android.com/about/versions/17/qpr3/download-ota)). Although QPR3 doesn't include API changes, Google provides images of the latest QPR beta builds so developers can test their apps as needed ([Android](https://developer.android.com/about/versions/17/qpr3/download-ota)).

9to5Google described Beta 3 as another big bug fixer ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-pixel/)). Among the fixes it lists are an inner display that remained black when unfolding the device, a display that randomly turned off and on, and a Force stop button that failed to terminate running applications ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-pixel/)). The list also covers poor video quality when using the device as a webcam and intermittent device crashes on the lock screen or shortly after startup ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-pixel/)).

Other listed fixes address apps that crash when BluetoothLeScanner.stopScan() is called with a null callback, and WPA-Enterprise Wi-Fi connections that fail when authenticating with PEAP ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-pixel/)). Fixes for the Mobile Data Quick Settings icon and for grouped notification icons and titles that appeared grayed out are also on the list ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-pixel/)).

In its walkthrough of Beta 3, 9to5Google lists a screenshot shortcut in the Power menu that captures the full screen, including status and navigation bars ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-everything-new/)). The same walkthrough lists the return of lockscreen blur and of app lock, along with a Camera Quick Settings Tile ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-everything-new/)).

Build DP11.261016.004 covers the Pixel 11, Pixel 11 Pro, Pixel 11 Pro XL and Pixel 11 Pro Fold, while DP11.261016.003 covers all other devices ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-pixel/)). System images are available for the Pixel 6a, Pixel 7, Pixel 7 Pro, Pixel 7a, Pixel Tablet, Pixel Fold, Pixel 8, Pixel 8 Pro, Pixel 8a, Pixel 9, Pixel 9 Pro, Pixel 9 Pro XL, Pixel 9 Pro Fold, Pixel 9a, Pixel 10, Pixel 10 Pro, Pixel 10 Pro XL, Pixel 10 Pro Fold, Pixel 10a, Pixel 11, Pixel 11 Pro, Pixel 11 Pro XL and Pixel 11 Pro Fold, as well as the Android Emulator ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-pixel/)). The emulator images support x86 (64-bit) and ARM (v8-A) ([Android](https://developer.android.com/about/versions/17/qpr3/download-ota)).

After a beta build is installed, a Pixel device is automatically enrolled in the Android Beta for Pixel program and offered continuous over-the-air updates to the latest beta builds until the user unenrolls it ([Android](https://developer.android.com/about/versions/17/qpr3/download-ota)). Users can return to the latest public build at any time by flashing the factory image ([Android](https://developer.android.com/about/versions/17/qpr3/download-ota)). Issues can be reported through the Android Beta Feedback app on Pixel devices ([9to5Google](https://9to5google.com/2026/10/29/android-17-qpr3-beta-3-pixel/)).
