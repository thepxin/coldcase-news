Anthropic announced on November 23, 2026, that Claude Ship, which can review pull requests, fix them and decide what is ready to merge based on policies each team sets, is available in beta ([Anthropic](https://claude.com/resources/articles/introducing-claude-ship)). TechCrunch described the product as a suite of artificial intelligence agents for automating code reviews, fixes and approvals of routine code changes ([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

According to TechCrunch, Claude Ship is launching in beta and rolling out to Claude Team and Enterprise plans for repositories on GitHub ([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)). Code Review is generally available, while PR Steward and Claude Approvals are in beta ([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

PR Steward addresses failing continuous integration checks, merge conflicts and feedback from Code Review ([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)). After every push, it comments on what it changed and how to roll the change back, if needed ([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

Claude Approvals then applies an approval policy that each team writes in natural language, as a file in the repository ([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)). The approval process can draw on signals that include Code Review findings or the company's own classifiers ([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

Anthropic recommends turning on Claude Approvals first in observe-only mode to build confidence ([Anthropic](https://claude.com/resources/articles/introducing-claude-ship)). Teams can also start with one repository and set monthly spending limits ([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).

## Details (as Reported)

- In its announcement, the company wrote that "Most teams want a person to approve every change," and noted that this is easy to keep up with when people write every line ([Anthropic](https://claude.com/resources/articles/introducing-claude-ship)).
- The same announcement stated: "On the Claude Code team, Claude writes most of our code" ([Anthropic](https://claude.com/resources/articles/introducing-claude-ship)).
- The announcement added that the team wanted everything after the pull request to move as quickly as the writing of the code ([Anthropic](https://claude.com/resources/articles/introducing-claude-ship)).
- Teams keep control over which review depth to use, such as Quick, Standard or Deep, and over which changes are escalated to a human for a decision ([TechCrunch](https://techcrunch.com/2026/11/23/anthropic-launches-claude-ship-letting-ai-agents-review-fix-and-approve-code-changes/)).
